# Matrix Algorithms

Two browser-based, interactive demonstrations of numerical linear algebra:

- **[Gaussian elimination](GaussianElimination.html)** — step through row reduction, compare pivoting strategies, and explore the PALU factorization \(PA=LU\).
- **[Jacobi method](DiagonalizationJacobi.html)** — diagonalize a real symmetric matrix with plane rotations and inspect the eigenvalues, eigenvectors, and convergence.

Open [index.html](index.html) in a browser to choose a demo. Both pages support English and Hungarian. No installation or build step is required; MathJax is loaded from a CDN to typeset the mathematics.

The site is published with [GitHub Pages](https://nagygp.github.io/matrix-algorithms/).
